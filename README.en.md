# SXKJ-Open-After-School-Server

# I. System Overview

<font style="color:rgb(31, 35, 40);">The Ziran · Zhi Ran Cloud After-School Service Management Platform (Changsha Sixuan) is a comprehensive service platform for primary and secondary schools that integrates teaching and education management, student management, home-school communication, home-school collaboration, AI-assisted exam grading, student course selection and schedule adjustment, and after-school study trips. The platform delivers unified management of public course selection, invitation-based course selection, and administrative-class course selection, covering the entire closed loop of after-school service workflows. Supported scenarios include teacher scheduling, student course selection and schedule adjustment, homeroom teacher schedule adjustment, student leave requests, teacher roll call, student whereabouts tracking, one-click student safety alerts, and after-school statistics (by teacher and by student). The core features of the homeroom teacher's mobile workbench include My To-Dos, student schedule adjustment, attendance management, timetable management, evaluation management, natural class management, student leave, and after-school statistics (class-hour statistics, data dashboards, course evaluation analysis).</font>

# II. Software Architecture

## 1. System Architecture and Technology Stack

### 1.1 Overall Architecture

```plain
┌─────────────────────────────────────────────┐
│         Frontend (Web / H5 / Mini Program)   │
└───────────────────┬─────────────────────────┘
                    │ HTTPS
┌───────────────────▼─────────────────────────┐
│        Nginx (reverse proxy / static assets) │
└───────────────────┬─────────────────────────┘
                    │
┌───────────────────▼─────────────────────────┐
│      auth-server-api (core business service) │
│  Controller → Service → Mapper(DAO) → MySQL  │
│  · JWT authentication / API rate limiting    │
│    / data permissions (DataScope)            │
│  · @OperateLog operation-log aspect          │
└────┬──────────┬──────────┬──────────────────┘
     │          │          │
┌────▼───┐ ┌────▼────┐ ┌───▼─────────┐
│ MySQL  │ │  Redis  │ │ FastDFS file │
│ 5.7    │ │ (Redis) │ │   storage    │
└────────┘ └─────────┘ └─────────────┘
```

**Architectural pattern**: Monolithic layered architecture (Controller - Service - DAO), packaged as a multi-module Maven aggregation project.
Cross-cutting concerns are implemented through custom annotations (`@OperateLog`, `@AccessLimit`, `@DataScope`, `@NoNeedLogin`).

## 2. Project Modules

| Module | Description |
| --- | --- |
| `sxkj-edu-common` | Shared utility service: custom annotations, constants/enums, global exception handling, pagination, Redis wrappers, validators, and utility classes for Excel/PDF/date, etc. |
| `sxkj-edu-generator` | MySQL reverse-engineering code generator (Velocity templates) |
| `auth-server-api` | Core business service: basic services and business service APIs, third-party system integration, scheduled tasks, interceptors |

Internal layering of `auth-server-api`:

```plain
com.sxkj.edu
 ├─ controller    # Business API entry points, packaged by top-level menu; @OperateLog is mandatory
 ├─ service       # Interface definitions (IService) + implementations (ServiceImpl)
 ├─ domain        # Domain models: PO (table) / DTO (transfer) / VO (response) / AO (input)
 ├─ module        # Basic services - system management
 ├─ handle        # Global unified handling
 ├─ interceptor   # Global interceptors
 ├─ job           # Scheduled tasks
 └─ config        # Integration, messaging, monitoring, swagger configuration, etc.
```

#### Installation Guide

1. Get the code
   git clone [https://github.com/sxkj-jiang/SXKJ-Open-After-School-Server.git](https://github.com/sxkj-jiang/SXKJ-Open-After-School-Server.git)
   cd sxkj-open-after-school-server

2. Initialize the database
   2.1 Create the database (utf8mb4 encoding):
   CREATE DATABASE open_after DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

       2.2 Run the DDL script and initial data (see configs/open_after.sql); copy the entire content and execute it in Navicat;
       2.3 (Optional) Deploy FastDFS (tracker/storage) and confirm the `tracker-list` address is reachable.

3. Modify the Spring Boot environment configuration
   The project switches environments via `spring.profiles.active`. Configuration files are located in
   `auth-server-api/src/main/resources/`:

| File | Purpose |
| --- | --- |
| `application.yml` | Main configuration (profile, logging, thread pool, passing score) |
| `application-dev.yml` | Development environment (port 7081, context-path `/open/after/v1`) |
| `application-online.yml` | Test environment |

**Key configuration that must be changed** (do not use any sample password in the repository):
spring:
datasource:
url: jdbc:mysql://:3306/open_after?serverTimezone=Asia/Shanghai&useUnicode=true&characterEncoding=utf-8&useSSL=false         username:          password:        redis:         host:          port: 6379         password:

```plain
fdfs:
  tracker-list: <your-fastdfs-tracker>:22122
```

Also update key/secret items such as `aes.data.key` and `edu.user.encryptPassword` in `configs/application.properties` (always change these in production).

4. Start the service
   In IntelliJ IDEA, run: AfterSchoolApplication.java

5. Access the API documentation
   [http://localhost:7081/open/after/v1/doc.html#/home](http://localhost:7081/open/after/v1/doc.html#/home)
